# Portal de Solicitações Internas

Portal para que colaboradores registrem demandas internas (TI, RH, Compras, Financeiro e Infraestrutura) e acompanhem sua evolução até a conclusão.

> Documentação completa em construção.

## Estrutura

```
backend/   API REST (Express + Prisma + PostgreSQL)
frontend/  SPA (React + Vite + Tailwind + shadcn/ui)
docs/      Memorial técnico
```
